# Kubeerra Market Brief deliverables

Every morning issue adds its files here (D-041), starting with the 4 Nov 2026 issue.

| Folder | What | Kept |
| --- | --- | --- |
| `pdf/` | A4 PDF edition | 14 most recent issues |
| `gmail/` | Email HTML for Gmail | 14 most recent issues |
| `outlook/` | Email HTML for Outlook (classic, new and on the web) | 14 most recent issues |
| `whatsapp/` | Snapshot card (PNG) and its caption | 14 most recent issues |
| `text/` | Plain-text edition | 14 most recent issues |
| `check-reports/` | Automated checks, suggested subject and figures to confirm | Permanently |
| `reviews/` | Independent review log: findings and how each was resolved | Permanently |

The issue data files stay in `issues/` and are kept permanently. Older deliverables are removed
by `render/publish.py`; git history still holds every version.

Nothing here has been sent: Shriansh approves each issue before it goes to anyone. See
`docs/SENDING_GUIDE.md` for how to send the Gmail and Outlook files.
