## Regulatory and compliance guardrails

The report stays in one lane: SEBI excludes general market trends, broad-based indices and economic, political or market commentary from its definition of a research report, but not opinions or calls on individual securities or IPOs, which a distributor cannot publish.

**House rules:**

- Never promise or imply returns; mark any projection illustrative.
- Link the website's commission disclosures; describe services as distribution, never advisory.
- No grey market premium figures: they are unofficial and read as an IPO opinion.
- Every number comes from a named, fetched source with its date and time; nothing from memory. Provisional data is labelled provisional.
- Original writing only: summarise and link sources, never reproduce article text or images.

**Words the checker flags for human review:** advisory, adviser, advisor, IFA, wealth manager, portfolio management, research report, recommend, tip, target price, buy/sell/hold (as advice), multibagger, guaranteed, assured, risk-free, best fund, top picks, sure-shot. Flows such as "FIIs bought ₹X crore" are facts and stay.

## Editorial standards

Every story answers two questions in Kubeerra's voice, what happened and why it matters to an Indian investor, in plain words with a dated, sourced number.

**Story pattern.**

1. Tags: a topic (Markets, Flows, Economy, Global, IPO, Mutual funds) and a defined relevance level: Market-wide (moves broad indices or flows), Sector (one sector or asset class), or On the radar (worth knowing, no immediate effect).
2. Headline: sentence case, one complete thought, no truncation.
3. What happened: one or two sentences with figures, units, date and a source link.
4. Why it matters for Indian investors: one or two sentences on the transmission channel (for example, crude to the import bill to inflation), with no prediction or call.
5. Source line: publication name and link.

**Voice.** Calm, specific and plain; jargon explained at first use. Moves are described with numbers, not verbs like crash, bloodbath, frenzy or panic. When India lags global markets, the report gives context rather than alarm, and it never cheerleads either.

**Style.** No em dashes (commas, colons or parentheses instead). Indian number system: ₹4,240 crore, ₹1.2 lakh crore. Index moves to two decimals. Dates as 28 Oct 2026, times as 3:30 PM IST. Every number has a unit and an as-of time.

**Lessons from the reference sample** (Bajaj Capital, 28 Oct 2026; used for inspiration only, never copied):

| Keep | Fix |
| --- | --- |
| "What is happening" plus "why it matters for India" structure | Several outlook columns repeat one paragraph twice, and green headings are truncated copies of the text below |
| Impact labels for quick scanning | Labels are undefined; ours carry stated criteria |
| A source and a full-article link per story | ALL-CAPS headlines are slow to read; ours use sentence case |
| A mix of macro, flows, corporate and primary-market news | Image slots show "image not found" placeholders; ours use no decorative images |
|  | No index levels, flow figures, currency or crude anywhere; ours lead with a data snapshot |
|  | Directional calls (bearish for oil marketers, bullish for capital goods, an index re-rating) and a grey market premium; ours give context without calls |
|  | Weak India relevance (Cupertino real estate) and mismatched text (an NCD story's outlook discusses an earnings release); every item passes an India-relevance and headline-match check |
|  | A sentence split mid-name ("The Rs 275.40-crore IPO of M.K."); every item is proofread whole |
|  | No mutual fund section, no education, no data timestamps; ours has all three |

**Three ways to get the numbers.**

1. Public sources with human confirmation of about 12 headline figures each day: low cost and a ten-minute check, but the licensing question remains open. Suggested for the pilot.
2. A licensed feed from an NSE-authorised vendor, or a platform API whose terms allow display in client communications: reliable automation at a cost.
3. The company's own platform: the REDVision website already shows indicative index data, so ask whether that licence covers emails and PDFs.

No number is ever written from a model's memory; language models can produce plausible but wrong prices, so each figure is fetched, cited and checked against a second source.

One editor writes the issue so the voice stays single. A larger swarm adds cost and inconsistency without better output.

**On public skill collections.** They add little here: the existing pdf, frontend-design and dataviz skills cover rendering and charts, and the skill that matters is the project's own daily-report skill.

**Not worth adding now.** AI image generation (synthetic imagery weakens trust in a financial publication, and the design document favours restrained visuals); presentation tools; paid email-testing suites until the list is large; heavy frontend frameworks for email.

## Handover guide for a new Claude account

A new account can resume work from this record and the repository alone; nothing else from this conversation is needed.

1. Give the new account the repository (attach it in a Claude Code session) or, before the repository exists, this record exported as Markdown and uploaded to a Claude Project.
